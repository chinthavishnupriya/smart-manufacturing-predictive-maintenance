# Sample Maintenance Guide — Demonstration Only

This is illustrative sample content for testing retrieval. It is not an
official equipment manual. Always follow the manufacturer's instructions
and approved site safety procedures.

## Temperature Anomaly
If a machine's temperature rises above its normal operating range:
1. Verify the sensor reading and compare it with the approved machine limits.
2. Review recent temperature trends and operating conditions.
3. Follow the site-approved inspection and escalation procedure.
4. Do not change operating limits without engineering authorization.

## Vibration Anomaly
If vibration rises significantly compared with the machine's baseline:
1. Verify the sensor and check the trend.
2. Arrange an inspection according to the site's maintenance procedure.
3. Possible investigation areas may include alignment, bearings, mounting,
   and looseness. These are possibilities, not confirmed diagnoses.
4. Follow the manufacturer's isolation and safety requirements before work.

## Pressure Anomaly
If pressure is outside the approved operating range:
1. Verify the reading and compare it with the manufacturer's specified limits.
2. Follow the approved shutdown or escalation procedure for that equipment.
3. Do not adjust pressure settings without authorization.

## High Predicted Failure Probability
If the predictive model reports failure probability above 80 percent:
1. Flag the machine for maintenance review.
2. Record the machine ID, timestamp, sensor values, and model probability.
3. Check whether an equivalent work order already exists.
4. Use the site's approved risk assessment and maintenance process to decide
   the next action. A model prediction is not proof that failure will occur.

## Remaining Useful Life
Remaining Useful Life (RUL) is a model estimate of the remaining operating
cycles or time before a defined end-of-life condition. Interpret it using
the model's documented units and validation limits. RUL is an estimate,
not a guaranteed failure time.
